Mekanik pertanyaan:

- Jawaban benar memberi bonus pertumbuhan ke tanaman pada batch tersebut.
- Jawaban salah tidak mengurangi koin; air tetap tersimpan.
- Panen langsung, tanpa pertanyaan.

Cara menjalankan:
Ekstrak seluruh ZIP ke satu folder, lalu buka index.html dengan Live Server.
